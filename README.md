# TODO-лист на Flask + SQLite

Простое веб-приложение для управления задачами.

## Функции
- Добавление задач
- Просмотр списка задач
- Отметка задач как выполненных

## Как запустить
1. Установи Flask: `pip install flask`
2. Запусти: `python app.py`
3. Открой: `http://127.0.0.1:5000`

## Маршруты
- `/` — список задач
- `/add/<title>` — добавить задачу
- `/done/<int:task_id>` — отметить выполненной

## Технологии
- Python
- Flask
- SQLite
