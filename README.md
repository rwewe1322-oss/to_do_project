# TODO-лист на Flask + SQLite

Приложение для управления задачами с веб-интерфейсом.

## Функции
- Добавление задач (через форму)
- Просмотр списка задач
- Отметка задач как выполненных

## Стек
- Python
- Flask
- SQLite

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти: `python app.py`
3. Открой: `http://127.0.0.1:5000`

## Маршруты
- `GET /` — список задач
- `GET/POST /add/` — добавить задачу
- `GET/POST /done/` — отметить выполненной
